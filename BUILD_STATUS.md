# Build status

Rokid To Do v0.1.0 is built by `.github/workflows/build-release.yml` against Android API 36 and the published Rokid Nexus `bus-client` SDK. Successful builds publish `RokidToDo-v0.1.0-debug.apk` as a workflow artifact; main-branch builds also publish it to the `v0.1.0` GitHub release.

This branch exists only to exercise the first pull-request CI build for v0.1.0.
